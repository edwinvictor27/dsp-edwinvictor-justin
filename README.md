
# 🏠 House Price Prediction Using Linear Regression

## 📌 Project Overview

This project focuses on predicting house prices using **Linear Regression**, a supervised machine learning algorithm.

The objective is to analyze housing-related features and develop a machine learning model capable of estimating property prices.

This project was developed to strengthen practical knowledge of data preprocessing, feature engineering, model training, and machine learning evaluation.

---

## 🎯 Objectives

- Analyze housing data and identify relevant features.
- Perform data preprocessing and preparation.
- Apply Linear Regression for price prediction.
- Train and evaluate a machine learning model.
- Save trained models and preprocessing objects for reuse.

---

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Machine Learning:** Linear Regression
- **Data Analysis:** Pandas, NumPy
- **Machine Learning Library:** Scikit-learn
- **Development Environment:** Jupyter Notebook

---

## 🔍 Methodology

### 1. Data Preparation

- Loaded and explored the housing dataset.
- Identified relevant features for price prediction.
- Prepared the data for machine learning.

### 2. Data Preprocessing

- Applied required data cleaning and preprocessing techniques.
- Used feature scaling and encoding where applicable.
- Prepared the dataset for model training.

### 3. Model Development

Implemented a **Linear Regression** model to predict house prices based on the selected input features.

### 4. Model Persistence

Saved the trained model and preprocessing objects for future predictions and reuse.
